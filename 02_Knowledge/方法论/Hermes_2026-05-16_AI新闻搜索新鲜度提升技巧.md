# AI 新闻搜索新鲜度提升技巧

**背景**
Hermes 通过 mmx search 命令搜索 AI/财经/产业新闻生成简报。搜索结果默认按相关性排序而非时间，且搜索词的质量直接影响结果新鲜度。通过多次执行，沉淀出一套提升新闻搜索新鲜度的技巧。

**核心洞察**

有五个关键技巧可以显著提升搜索结果的新鲜度：

**第一，中文日期约束**。在 query 中加入具体日期的汉字形式（如 `"2026年5月9日 纳米"`），比用英文日期（如 `"nanotech May 9 2026"`）返回的结果更新。因为中文媒体发布新闻时使用中文日期字段，更容易被中文搜索引擎索引。

**第二，中文实体名优先**。搜索中国科技新闻时，用中文专有名词直接搜索效果最好（如 `"汉原2号"`、`"本源悟空"`、`"考拉博客"`）。英文名往往无结果或结果过时，因为中国科技媒体倾向于使用中文命名。

**第三，多轮渐进式搜索**。先用宽泛关键词（如 `原子级制造 2026年5月`）发现一批实体名，再对发现的实体名做二次精准搜索。例如第一轮发现"本源悟空"后，第二轮搜索 `"本源悟空 量子计算 2026年5月"`。

**第四，snippet 清洗**。返回的 snippet 含 HTML 标签（`</p><p>`），需要彻底清洗。正确的做法是用正则 `re.sub(r'<[^>]+>', '', text)` 去除所有 HTML 标签，不要只用简单的字符串 replace（容易遗漏嵌套标签）。

**第五，搜索结果为空时的处理**。去掉具体日期，改用月级别约束（如 `"2026年5月 纳米制造 突破"`），避免日期过细导致零结果。

**对Jerry的意义**
这些技巧让每日简报的内容质量更高——新闻更新鲜、更贴近中国产业链实际。在 MLCC、半导体、原子级制造等垂直领域的简报中，中文实体名优先尤为重要，因为这些行业的核心信息源主要是中文媒体。

**延伸思考**
mmx search 的默认排序是相关性而非时间，如果一定要按时间排序，可以在 query 中加入明确的日期约束词。此外，每次搜索的 timeout=30 秒，建议在 Python 中对每个关键词单独 try-except，避免一个关键词超时卡住整个批次。
