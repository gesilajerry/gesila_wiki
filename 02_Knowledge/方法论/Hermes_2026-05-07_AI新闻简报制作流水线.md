# AI新闻简报制作流水线

**背景**
Hermes Cron任务每天多次（04:00、12:00、18:00等）自动生成AI热点简报并推送飞书，形成稳定的自动化流水线。

**核心洞察**
完整流水线：mmx多关键词搜索 → Python合并去重 → HTML标签清洗 → 飞书post消息发送，全程无需人工干预。

步骤分解：
1. **搜索**：`mmx search query --q "关键词" --output json`，支持多关键词并发
2. **合并去重**：用title前30字符做key去重，多关键词结果合并后按时间排序
3. **清洗**：snippet含HTML标签 `</p><p>`，用 `re.sub(r'<[^>]+>', '', html)` 清除
4. **发送**：飞书post消息，content格式为 `[[{...}], [{...}], ...]`

```python
def search_briefing(keywords, max_results=5, max_total=12):
    all_results = {}
    for kw in keywords:
        results = mmx_search(kw, max_results=max_results)
        for r in results:
            key = r['title'][:30]
            if key not in all_results:
                all_results[key] = r
    items = list(all_results.values())
    items.sort(key=lambda x: x.get('date', ''), reverse=True)
    return items[:max_total]
```

**对Jerry的意义**
- 每日AI简报已稳定运行，成功率100%（13/13任务）
- 8条新闻+今日关注的格式被验证有效
- 可复制到财经新闻、MLCC行业晨报等其他垂类简报

**延伸思考**
- mmx search 默认按相关性排序，非时间排序；需加日期关键词如"AI新闻 2026年5月"可改善
- 关键词空格分隔=短语匹配，效果优于连续词
- 每条新闻格式：标题+30字摘要+来源链接+分隔线
