# 小红书梵高图文三轮并行流水线

**背景**
2026-05-15当天，xhs-vangogh-r1/r2/r3 三个 cron job 在不同时间段并行运行，生成三个独立主题的梵高融合风图文内容，每轮10张图 + 专属情绪文案，产出后发飞书通知。

**核心洞察**
三轮流水线的设计模式：
- **r1**（10:00执行）：主题「星空原野」，情绪文案「抬头的那一瞬，整个宇宙都在为你沉默」，10张插画（星空、帐篷、孤独的树、流星、露珠、地平线、狼、野花、篝火、黎明）
- **r2**（17:30执行）：主题「独居女孩日常」，情绪文案「一个人的房间，住着整个世界的安静」，10张场景图（晨光卧室→窗边咖啡→阳台晾衣→厨房热汤→沙发撸猫→浴室蒸汽→衣柜选衣→夜灯→阳台看书→深夜泡澡）
- **r3**（22:30执行）：主题「治愈森林」，情绪文案「有些路，一个人走的时候，才听得见自己的声音」，10张场景图

共同特征：强情绪主题 + 梵高视觉语言（厚笔触、肌理感）+ 真实场景细节。飞书发送时包含主题、情绪文案、10张图三部分，供手动发布小红书。

关键发现：r1 的飞书发送备注揭示了自动化发布的根本限制——小红书需要浏览器扫码登录，180秒超时无法完成，因此生成与发布必须分离。飞书是最终通知渠道，而非发布渠道。

**对Jerry的意义**
这套流水线解决了内容量产问题：每天3个主题、30张图，情绪差异化覆盖（宇宙感/独居感/森林感），适合小红书账号的日更需求。但必须接受"生成自动化、发布手动化"的现实，自动化发布小红书在这个环境里不可行。

**延伸思考**
可以探索小红书发布的手动化最优流程——比如用浏览器插件/自动化工具绕过扫码，或者固定时间提醒 Jerry 手动发布。内容本身（梵高融合风插画 + 情绪文案）已经完全可量产，关键是打通最后一步发布环节。可考虑引入小红书创作服务平台的 API 模式（扫码cookie后自动发布）。
