# AI简报自动流水线标准架构

**背景**
Hermes 每日运行多条行业简报任务（AI热点/半导体/MLCC/原子级制造/财经），每条任务都包含相同的搜索→清洗→发布流程。这一流程在5月23日的推送日报中被完整记录，形成可复用的标准架构。

**核心洞察**
AI简报流水线分为5个标准化阶段：

**第一阶段：多关键词并行搜索**
```python
def mmx_search(query, max_results=10):
    cmd = f'mmx search query --q "{query}" --output json'
    r = subprocess.run(cmd, shell=True, capture_output=True, text=True, timeout=30)
    data = json.loads(r.stdout)
    results = []
    for item in data.get('organic', [])[:max_results]:
        results.append({...})
    return results
```
多条简报任务共享同一搜索函数，通过多关键词合并去重（`search_briefing`）。

**第二阶段：HTML摘要清洗**
`snsippet`字段包含HTML标签（`</p><p>`），必须清洗：
```python
def clean_snippet(html):
    text = re.sub(r'<[^>]+>', '', html)  # 去除所有HTML标签
    text = text.replace('﻿', '').strip()
    return text[:200]
```

**第三阶段：多关键词去重合并**
用title前30字符做去重key，避免同一新闻被多个关键词重复引入：
```python
items.sort(key=lambda x: x.get('date', ''), reverse=True)
return items[:max_total]
```

**第四阶段：飞书Post消息发送**
content格式为数组的数组，每段落独立包在数组里：
```python
content = [
    [{"tag": "text", "text": "第一行内容"}],
    [{"tag": "text", "text": "第二行内容"}],
]
post_content = {"zh_cn": {"title": "标题", "content": content}}
```
⚠️ 报230001错误时，检查content是否为数组的数组而非单层数组。

**第五阶段：发布到Koala博客**
通过 `blog-publisher` skill 的 token 自动发布到"市场销售-专业知识"板块。

**对Jerry的意义**
这一架构已驱动每日18条Cron任务的稳定运行，是Hermes自动化内容的核心生产线。任何新增行业简报任务，只需替换关键词列表和板块配置，即可快速复用。

**延伸思考**
可进一步抽象为通用新闻简报模板：输入关键词列表 → 自动搜索 → 清洗 → 生成markdown → 发布双平台。配合 cron-job-with-multi-skills 的子任务分解模式，可实现一条命令触发多条简报并行生成。
