# 小红书梵高图文日更流水线

**背景**
2026年5月24日，小红书梵高图文日更流水线R1/R2/R5三个批次全部成功执行。每日10张梵高融合风插画 + 情感文案 + 自动发布，全流程稳定运行。

**核心洞察**
流水线标准架构：

```
主题选择 → mmx生成图片 → 文案生成 → 小红书API发布
```

**产出模式**：
- 图片数量：每次10张，3:4竖屏梵高厚笔触肌理风格
- 文案公式：季节/场景关键词 + 情感哲学句
- 执行节奏：R1（10:06）、R5（14:04）、R2（17:34），每日3批

**文案风格特征**：
| 日期 | 主题 | 文案 |
|------|------|------|
| 2026-05-24 R1 | 火山湖泊（长白山天池） | 火与水相遇，是地球最浪漫的事。 |
| 2026-05-24 R2 | 茶山春色 | 茶叶是时间的艺术，等一等才会甜。 |
| 2026-05-24 R5 | 春日花海 | 花开了，世界就亮了。 |

**对Jerry的意义**
- 已验证"主题 + 梵高厚笔触 + 情感文案"的组合是有效的小红书内容公式
- 全流程无报错，产出稳定，可以作为日常运营的常规工作流
- 每天3批次的节奏覆盖早中晚三个时段，最大化曝光

**延伸思考**
梵高风格插画+情感文案的核心逻辑：视觉上用艺术感建立差异化认知（不与摄影/emoji账号竞争），文案上用生活哲学引发情感共鸣而非信息价值。后续可测试"情绪文案"（引发好奇/感伤/温暖）vs "知识文案"（传递信息）的点击率差异。
