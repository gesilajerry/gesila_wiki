# 小红书梵高图文情绪主题公式

**背景**
Hermes 运行 xhs-vangogh 流水线，每日 3 个批次（r1/r2/r3）并行生成小红书梵高融合风图文。每批次 10 张原创插画 + 情绪文案 + BGM + 慢速 TTS。通过多批次数据对比，可以提炼出高共鸣内容的公式。

**核心洞察**

梵高融合风图文的核心公式：**强情绪主题 + 梵高视觉语言 + 真实感场景细节 = 用户共鸣**。

这个公式在 2026-05-16 的三批次中得到了完整验证：

第一批次"静谧黄昏"产出的情绪文案是："黄昏是白天的尾声，也是夜晚的前奏，刚好够你喘口气。"——精准命中都市人"喘口气"的情绪需求。

第二批次"治愈森林"产出的 10 个场景依次为：阳光斑驳的森林入口 → 巨大老树下落叶与青苔 → 森林深处透出暖光的小木屋 → 溪水流过苔藓覆盖的石子 → 一只小鹿在树影里低头喝水 → 午后森林光柱（丁达尔效应）→ 树梢间漏下的金色光线 → 林间野花空地 → 雨后湿润泥土与蘑菇 → 夕阳在地上投下碎金。情绪文案："有些路，一个人走的时候，才听得见自己的声音。"——直击"独处自愈"情绪。

**对Jerry的意义**
这个公式是流水线的方法论核心：情绪主题决定文案方向（如"独居自愈"、"静谧黄昏"、"田园归隐"），梵高视觉语言确保风格一致性，场景细节让插画有真实感和代入感。三者缺一不可——只有情绪主题而无视觉语言支撑会变成空洞鸡汤；只有梵高笔触而无真实场景细节会失去共鸣锚点。

**延伸思考**
情绪主题的选择也有规律：优先选择都市人普遍存在的情绪缺口——孤独感、疲惫感、逃离感、治愈渴望。不选过于具体的情绪（如失恋、丧亲），而选泛化的、轻量可自愈的情绪——因为小红书用户刷到笔记时处于"泛浏览"状态，轻量情绪更容易快速共鸣并点赞收藏。

梵高视觉语言的关键特征：厚笔触肌理、鲜明色彩对比（尤其是金黄/橙红与深蓝的对比）、旋涡状星空笔法、阳光下建筑物轮廓光。场景细节要具体到"一棵树"、"一只鹿"、"一束光"——用单数不用复数，增加画面感。
