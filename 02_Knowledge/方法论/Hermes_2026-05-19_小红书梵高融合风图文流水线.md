# 小红书梵高融合风图文流水线：内容SOP方法论

**背景**
2026-05-19当天xhs-vangogh流水线完成5个批次（r1-r5），涵盖向日葵田、沙漠绿洲、童趣时光、湖边日落、草原星空5个主题。图片全部生成成功（累计50张），文案情绪化叙事+分场景画面感。

**核心洞察**
这套流水线的核心方法论是**情绪锚点+场景分镜+梵高视觉语言**：

1. **情绪锚点**：每期一句核心情绪文案（如"只要向着太阳，就没有悲伤的角落"、"星星那么近，好像伸手就能够到"），情绪要具体、有画面感
2. **场景分镜**：10张图=10个连续场景，有起承转合（湖边日落：湖面如镜→栈桥夕阳→芦苇摇曳→鸳鸯戏水→空椅温暖→荷花橙红→远山剪影→白鹭单脚→渔火小船→最后一缕阳光）
3. **梵高视觉语言**：厚笔触肌理+扁平治愈构图，色调以金黄、橙红、深蓝为主
4. **自动发布**：xhs-cli + BHR浏览器自动化，实现无人值守发布

**分场景画面感文案公式**：
```
[情绪句] + [10个场景编号：具体画面描写]
```
例："星星那么近，好像伸手就能够到。"
- 第1帧：银河横跨草原夜空，繁星如钻
- 第7帧：篝火旁仰望星空，火星飞舞
- 第10帧：黎明的天空慢慢泛起微光

**对Jerry的意义**
这套流水线已稳定运行多日，每日10张图+文案+自动发布是可持续的内容生产模式。草原星空主题成功说明自然+星空+情绪共鸣类内容效果好。

**延伸思考**
r3和r5都用了自然景观+情绪锚点策略，效果稳定。后续可选主题方向：城市夜景（霓虹）、四季花卉、童年记忆（亲子）。注意避免政治/争议题材。
