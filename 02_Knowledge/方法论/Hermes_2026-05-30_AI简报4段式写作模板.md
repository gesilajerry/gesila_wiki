# 行业简报4段式写作模板

**背景**
Hermes在2026年5月运行新闻简报cron任务时，沉淀出一套适用于所有垂直行业简报（半导体/MLCC/原子级制造/财经）的标准化写作框架。该模板控制字数在900字以内，适合飞书群推送和博客发布。

**核心洞察**

## 标准格式（4段式，900字以内）

```
💡 {行业}产业晨报 | YYYYMMDD

【今日要闻】
（3-5条，每条：事件标题 + 一句话摘要）

【技术进展】
（3-5条，每条：技术名称 + 核心进展）

【市场动态】
（3-5条，每条：市场事件 + 影响简述）

【今日关注】
（2-3句话综合评论，含判断和展望）
```

## 各段落写作规范

**【今日要闻】**
- 来源：政策新闻、大厂动态、重大事件
- 写法：事件标题（事实）+ 一句话影响
- 字数：150-200字

**【技术进展】**
- 来源：技术突破、研发进展、专利发布
- 写法：技术名称 + 核心进展 + 意义
- 字数：150-200字

**【市场动态】**
- 来源：产能变化、价格波动、财报数据
- 写法：市场事件 + 数据支撑 + 趋势研判
- 字数：200-250字

**【今日关注】**
- 写法：综合评论，2-3句话，包含判断和展望
- 语气：分析师视角，有观点有结论
- 字数：100-150字

## 写作要点

1. **数据驱动**：每条新闻尽量带数字（产能利用率、良率、涨幅%），增强可信度
2. **中国视角**：国产替代、政策回应等角度优先，体现本土立场
3. **因果串联**：今日要闻→技术进展→市场动态→今日关注，形成逻辑闭环
4. **控制长度**：全程900字以内，保证飞书阅读体验

**对Jerry的意义**

这套模板让他可以快速生成高质量行业简报，供Koala内网博客和飞书群使用。模板是通用的，适用于任何垂直行业，只需替换行业关键词即可。4段式结构让读者能快速扫读、定位兴趣段落。

**延伸思考**

该模板可扩展为「日/周/月」不同频次的简报格式：日刊侧重快讯（今日要闻为主），周刊侧重深度（今日关注占更大比重），月刊侧重复盘（数据汇总+趋势判断）。
