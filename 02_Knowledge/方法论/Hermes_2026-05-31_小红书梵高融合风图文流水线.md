# 小红书梵高融合风图文流水线

**背景**
xhs-vangogh-r1~r5系列任务已形成稳定的自动化流水线，每天自动生成10张梵高融合风插画（3:4竖屏）+情绪文案+BGM+慢速TTS，发布到小红书并推送飞书通知。这是一套可复用的内容生产框架。

**核心洞察**
1. **流水线架构**：mmx生成10张图（梵高厚笔触+扁平治愈构图，3:4竖屏）→ 生成情绪文案（一句话场景描述）→ TTS配音+BGM → 交叉淡化视频拼接 → BHR自动化发布小红书 → 飞书通知。核心是批量出图+固定风格锚点。

2. **风格锚点设计**：用"梵高厚笔触肌理+扁平治愈构图"作为风格锚点锁定，每次生成保持一致性，同时允许场景内容变化。这解决了AI生成图片风格飘移的常见问题。

3. **情绪文案公式**：短句场景描述（如"光在头顶跳舞，像一场亿万年的约定"），配合图片形成叙事张力。文案不解释画面，而是延续画面情绪。

4. **图片尺寸规范**：3:4竖屏是小红书图文笔记的主流规格，生成时直接指定尺寸，避免后期裁剪损失画质。

5. **飞书通知内嵌**：脚本内直接调用飞书API发送通知，无需手动操作，实现真正的"躺赢"式自动化。

**对Jerry的意义**
这套流水线的设计思路（风格锚点+场景变化+多模态组合）可以复用到其他内容创作场景，如：不同艺术风格的名画解读、不同产品的图文种草。理解"锚点锁定+内容变化"是批量内容生产的关键。

**延伸思考**
内容流水线的核心不是工具，而是对"什么是不变的、什么需要变"的判断。风格锚点、品牌调性是常量；场景、内容、话题是变量。搭建自动化流水线之前，先把这两种变量区分清楚。
