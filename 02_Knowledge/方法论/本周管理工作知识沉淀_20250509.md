# 本周管理工作知识沉淀

基于本周工作实际问题提炼，适用于公司各业务线参考执行。

---

## 一、交接清单制度

### 核心原则
任何跨阶段节点移交，必须"有清单才移交、有签字才生效"。空白清单是最大的风险源头。

### 适用范围
- 设计→采购
- 采购→制造/装配
- 制造→调试
- 调试→验收交付
- 人员离职/调岗

### 操作规范
1. 移交方在移交前1个工作日准备清单初稿
2. 清单必须包含：序号、项目名称、数量/状态、验收标准、双方签字栏
3. 接收方逐项核查，实物与清单不符处标注说明
4. 双方签字各执一份，归档至项目文件夹
5. 若无清单，接收方有权拒绝签字，由此产生的延误由移交方承担

### 量化标准示例

| 类型 | 量化指标 |
|------|---------|
| 设备类 | 真空度、束流强度、漏率（Pa·L/s） |
| 电气类 | 绝缘电阻、接地电阻、功率因数 |
| 机械类 | 公差等级、表面粗糙度、形位公差 |
| 文件类 | 版本号、图纸张数、技术要求条目数 |

### 常见错误
- 以口头交接代替书面清单
- 双方签字栏空白
- 清单无量化标准（写"正常"而非"漏率<1×10⁻⁵ Pa·L/s"）
- 交接后才发现问题，责任无法追溯

## 二、技术文件双向签收制度

### 核心原则
技术文件一进一出都必须有记录。无签收=无交付，无版本号=无效文件。

### 向外发送（发出方）
1. 每次发送图纸/技术协议，填写《文件发送记录表》：文件名称、版本号、接收方、发送日期、签收人
2. 要求接收方工程师签字或盖公章返回
3. 若接收方拒绝签字，须由发出方上级协调处理
4. 邮件发送须含回执确认；纸质文件须保留快递签收单

### 向内接收（接收方）
1. 收到文件后24小时内登记：文件名、版本号、来源、接收日期
2. 与项目需求核对，有疑问立即书面反馈
3. 分发至内部使用时，同步更新《文件分发清单》

### 图纸外发分级审批

| 密级 | 内容 | 审批人 |
|------|------|--------|
| 绝密 | 核心技术参数、自研工艺 | 两名负责人双签 |
| 机密 | 重要工艺参数、供应商信息 | 直接上级单签 |
| 秘密 | 通用图纸、非核心技术文件 | 项目负责人 |

### 版本控制规则
- 版本格式：V1.0（正式版）、V1.1（修订版）、V2.0（大版本）
- 每次修订须在文件首页记录修订说明、修订日期、修订人
- 旧版本标注"已作废"，不得继续使用

## 三、外采件到场验收标准

### 核心原则
非标准件/定制件到货后，禁止跳过验收直接进入装配序列。等结果等货，不等结果先装配。

### 验收流程
到货通知 → 外观检查 → 数量清点 → 规格核对 → 性能测试 → 合格入库/不合格退换

### 不同类型验收标准

**机械加工件**
- 尺寸复测：关键尺寸须逐一测量，记录实测值与图纸要求偏差
- 公差判定：超出图纸允差范围直接退换，不接受"差不多"
- 表面质量：锈蚀、磕碰、变形不得进入装配

**电气部件**
- 绝缘电阻≥100MΩ（500V摇表）
- 接地电阻≤4Ω
- 通电测试48小时无异常

**真空组件**
- 氦质谱检漏：漏率<1×10⁻⁹ Pa·L/s
- 烘烤除气后真空度达标

**定制件（最易出问题）**
- 到场先做抽检，不全检（成本高）
- 抽检比例不低于10%，发现问题100%退换
- 保留样品与供应商出厂检验报告对照

### 验收记录要求
每次验收填写《到货验收记录表》，包含：供应商名称、到货日期、抽检数量、合格数量、不合格项、处理结果。记录保存至项目验收完成后2年。

## 四、付款节奏与回款绑定规则

### 核心原则
合同付款节点须与对方实际履约能力绑定，先回款后付款是底线，不接受"对方没到账我先垫"。

### 付款优先级分类

| 优先级 | 类型 | 规则 |
|--------|------|------|
| A | 新供应商首单、定制件/非标件、金额超5万 | 先款后货 |
| B | 标准件采购、金额5万~20万 | 30%预付+70%到货 |
| C | 辅料、低值易耗品、金额5万以下 | 货到付款 |

### 预付款规则
- 预付款不超过合同额的30%
- 预付款前须核查对方最近一期财务报表（负债率>70%不预付）
- 大额预付须签订预付款保函

### 回款节点管控

| 客户类型 | 回款节点 | 财务预警时间 |
|---------|---------|------------|
| 高校/科研院所 | 合同签订30%+设备交付60%+验收10% | 到期前14天 |
| 企业客户 | 合同签订20%+发货40%+验收30%+尾款10% | 到期前7天 |
| 政府项目 | 按财政拨款节奏，无预付不发货 | 按拨款通知提前30天 |

### 禁止行为
- 无合同付款
- 预付超过30%
- 对方未回款己方先发货（特批除外，须书面记录）
- 发票与合同金额/抬头不符仍付款

## 五、需求提出与审核分离原则

### 核心原则
提出需求的人不审核需求，审核需求的人不提出需求。权力与责任分离，防止需求失真。

### 典型应用场景

**招聘需求**：用人部门填写岗位职责、任职资格、工作地点；人事部门审核薪资范围是否在预算内、JD是否符合公司表述规范；最终审批权归人事部门。

**采购需求**：业务部门提出规格型号、数量、用途、需求日期；采购部门审核供应商资质、价格合理性、交期可行性；最终审批权归采购部门与财务共同确认。

**技术方案需求**：工程师提出技术路线、参数指标、实现路径；技术负责人审核技术可行性、与其他项目的资源冲突；最终审批权归技术负责人。

### 职责边界
- 提出方：负责需求真实性、必要性证明
- 审核方：负责合规性审查，不负责验证"是否真的需要"
- 审核不通过须书面说明原因，提出方有权申诉

## 六、关键岗位AB角与知识冗余制度

### 核心原则
核心岗位不能只有一个人知道怎么做。一个人走了，能力不能走。

### AB角定义
- A角：主责人，对该项工作负最终责任
- B角：A角的备岗，掌握A角80%以上的工作内容，可随时接替

### 覆盖范围
- 技术负责人（每个项目至少1名备岗）
- 采购负责人
- 财务核心岗位
- 核心设备操作岗位（离子溅射、团簇设备、真空系统等）
- 关键供应商对接人

### 操作要求
1. 每季度B角须独立完成一次A角工作（由直接上级指定）
2. 核心操作步骤须形成SOP文档（Word/截图/视频均可），存于共享盘
3. 人员离职前须完成工作交接清单，双方签字，直接上级监交
4. 离职后3个月内B角独立承担责任的工作质量纳入B角考核

### 知识冗余检查清单（每半年一次）

| 检查项 | 标准 |
|--------|------|
| 核心岗位是否有B角 | 是/否 |
| B角是否能独立完成A角80%以上工作 | 是/否 |
| SOP文档是否存在且最新 | 是/否 |
| A角离岗超过1个月是否有人接替 | 是/否 |

## 七、决策闭环追踪表

### 核心原则
会议/讨论中的每项结论，若未转化为"动作+责任人+完成时间+验收标准"，则视为未决策。

### 追踪表字段

| 字段 | 说明 |
|------|------|
| 决策事项 | 讨论的具体内容 |
| 决议结论 | 会议最终决定 |
| 动作分解 | 为完成决议须做的事 |
| 责任人 | 会议指定一人 |
| 完成时间 | 精确到日 |
| 验收标准 | 如何判断完成 |
| 当前状态 | 待启动/进行中/已完成/已逾期 |

### 操作流程
1. 会议/讨论结束后，主持人24小时内填写追踪表
2. 每工作日17:00前，责任人在群内简单汇报进度（1句话）
3. 每周定期查看追踪表，对"进行中"超过1周或"已逾期"的事项追责
4. 完成后责任人标记"已完成"并写明实际完成情况

### 禁止行为
- 会上决定，会后不提
- 追踪表填了但无责任人和完成时间
- 责任人换岗/离职未同步更新追踪表
- 状态长期"进行中"无人过问

## 附：制度执行检查机制

### 月度检查项
- 本月交接清单是否100%有签字
- 本月外采件验收记录是否完整
- 本月付款是否100%绑定回款节点
- 追踪表新增项24小时内是否录入

### 季度检查项
- 核心岗位AB角是否配置到位
- SOP文档是否有更新
- 制度执行违规事项统计并通报

### 违规处理
- 首次违规：书面警告
- 二次违规：扣减当月绩效
- 造成损失的：按损失金额的10%扣减责任人工资
