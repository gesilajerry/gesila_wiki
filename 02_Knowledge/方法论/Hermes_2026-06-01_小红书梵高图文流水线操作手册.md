# 小红书梵高融合风图文流水线操作手册

**背景**
Hermes 小红书自动化流水线（xhs-vangogh-r1~r5）已稳定运行，实现"AI生成10张梵高融合风插画 + BGM + TTS配音 + 自动发布"全链路闭环。每日按cron调度执行多批次，覆盖不同主题。

**核心洞察**

## 1. 流水线架构（四层）
| 层次 | 组件 | 功能 |
|------|------|------|
| 内容层 | 主题+文案 | 短句哲思文案（6-15字），适配10图连续故事 |
| 视觉层 | mmx图片生成 | 梵高厚笔触+漩涡星空+扁平治愈构图，10张连续场景 |
| 音频层 | BGM+TTS | 轻音乐BGM + 慢速TTS配音，增强沉浸感 |
| 发布层 | xhs-cli | 自动发布到小红书，图片+文案一键上传 |

## 2. 执行节奏
- 每批次间隔约2小时（r1~r5），主题不重复
- 单批次耗时：图片生成（各约30秒×10张）+ BGM + TTS + 发布 ≈ 15-20分钟
- 全部成功依赖：mmx可用、xhs-cli登录态有效、小红书账号无风控

## 3. 文案创作规律
- 短句哲思，一句话点题
- 例："水从高处跳下去，是重生，不是坠落。""花开了，世界就亮了。""同一个窗子，住着四个不同的世界。"
- 10张图讲述一个连续故事，有起承转合

## 4. 图片风格锚点（mmx提示词要素）
- 梵高标志性元素：厚笔触肌理、漩涡状星空、金色蓝黄色调、火焰般升腾的笔触
- 构图要求：扁平治愈 + 故事场景感
- 每张图对应一个分场景，共同构成完整叙事

## 5. 已知踩坑
- xhs-cli cookie过期 → 需重新扫码登录（xhs-qr-login）
- mmx生成并发限制 → 单批次10张串行，约需5分钟
- 小红书风控 → 短时间内发图过多会触发限流，分散批次可缓解

**对Jerry的意义**
小红书图文账号已形成稳定的梵高融合风内容标签，是品牌视觉稀缺性资产。5个账号同时跑不同主题，最大化日更效率，同时保持内容差异化。

**延伸思考**
当前流水线完全依赖 Hermes cron 调度，未来可考虑：
- 增加"热点话题联动"机制（搜索当日热点→自动选题）
- 打通飞书通知，发布后自动推送结果到飞书群
- 建立图文素材库，避免主题重复
