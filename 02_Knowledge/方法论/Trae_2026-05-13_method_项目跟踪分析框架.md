# 项目跟踪分析框架

> **方法类型**：分析方法论  
> **创建日期**：2026-05-13  
> **来源**：弈人科技、极睿科技项目跟踪实践

---

## 一、方法概述

**项目跟踪分析框架**是一套系统化的项目跟踪方法论，用于持续跟踪目标公司的商业模式、竞争格局、发展动态，并评估其可复制性和投资价值。

**核心价值**：
- 结构化信息收集，避免遗漏关键要素
- 标准化分析流程，提高分析效率
- 可复制性评估，指导创业/投资决策

---

## 二、五步分析法

### Step 1：公司概况扫描

**目标**：快速建立对公司的基础认知

**信息维度**：

| 维度 | 信息要点 | 数据来源 |
|------|----------|----------|
| 基本信息 | 公司名称、成立时间、总部位置 | 企查查、天眼查 |
| 融资历史 | 融资轮次、金额、投资方、估值 | 36氪、IT桔子 |
| 团队背景 | 创始人、核心团队、技术背景 | 官网、LinkedIn |
| 荣誉资质 | 行业奖项、专利、资质认证 | 官网、媒体报道 |

**输出模板**：
```markdown
| 维度 | 详情 |
|------|------|
| **公司** | XXX |
| **成立时间** | YYYY年 |
| **最新融资** | X轮，金额，时间 |
| **投资方** | 投资机构列表 |
| **核心团队** | 关键人物及背景 |
```

### Step 2：商业模式拆解

**目标**：理解公司的核心商业模式和盈利方式

**分析框架**：

```
商业模式画布九要素：
├── 客户细分：目标客户是谁？
├── 价值主张：提供什么核心价值？
├── 渠道通路：如何触达客户？
├── 客户关系：如何维护客户关系？
├── 收入来源：如何赚钱？
├── 核心资源：需要什么关键资源？
├── 关键业务：核心业务是什么？
├── 重要合作：关键合作伙伴是谁？
└── 成本结构：主要成本有哪些？
```

**输出模板**：
```markdown
**核心定位**：一句话描述公司定位

**技术底座**：
- 技术1：说明
- 技术2：说明

**商业模式**：
- 模式1：说明
- 模式2：说明
```

### Step 3：可复制性评估

**目标**：判断该模式是否可以被复制或借鉴

**评估维度**：

| 维度 | 评估要点 | 评分标准 |
|------|----------|----------|
| 行业门槛 | 数据、技术、牌照等门槛 | 高/中/低 |
| 资金需求 | 启动资金、运营资金需求 | 高/中/低 |
| 团队要求 | 技术团队、运营团队要求 | 高/中/低 |
| 时间窗口 | 市场窗口期是否关闭 | 紧张/适中/宽松 |
| 规模化潜力 | 是否具备规模化能力 | 大/中/小 |

**输出模板**：
```markdown
**可复制要素**：
- ✅ 可复制点1：说明
- ✅ 可复制点2：说明
- ❌ 不可复制点：说明及原因
```

### Step 4：竞争格局分析

**目标**：了解市场竞争态势和公司竞争地位

**分析框架**：

```
竞争分析五力模型：
├── 现有竞争者：主要竞争对手是谁？竞争激烈程度？
├── 潜在进入者：行业进入门槛？新玩家威胁？
├── 替代品威胁：是否有替代方案？
├── 供应商议价能力：上游供应商集中度？
└── 客户议价能力：客户集中度？转换成本？
```

**输出模板**：
```markdown
**竞争格局**：
- 头部玩家：XXX、XXX
- 竞争态势：描述
- 差异化优势：本公司的独特优势
```

### Step 5：风险提示

**目标**：识别潜在风险，为决策提供风险视角

**风险分类**：

| 风险类型 | 具体风险点 | 影响程度 |
|----------|------------|----------|
| 行业风险 | 行业周期、政策变化 | 高/中/低 |
| 技术风险 | 技术迭代、技术壁垒 | 高/中/低 |
| 竞争风险 | 竞争加剧、价格战 | 高/中/低 |
| 合规风险 | 数据安全、隐私保护 | 高/中/低 |
| 运营风险 | 人才流失、成本上升 | 高/中/低 |

**输出模板**：
```markdown
**风险提示**：
1. **风险类型1**：具体描述
2. **风险类型2**：具体描述
3. **行业共性**：行业普遍风险
```

## 三、实战案例

### 案例：弈人科技项目跟踪

**Step 1 - 公司概况**：
| 维度 | 详情 |
|------|------|
| **公司** | 弈人（上海）科技有限公司 |
| **最新融资** | PreA+轮 + PreA++轮，连续两轮亿元级（2026年5月11日官宣） |
| **投资方** | 国方创投（上海市数链基金）、成都交子资本（自贡市人工智能基金） |
| **营收里程碑** | 2025年AI数据业务收入过亿元，国内率先实现AI数据正向盈利 |

**Step 2 - 商业模式**：
- 核心定位：时空数据服务商
- 技术壁垒：自研"星汉时空模型"
- 商业模式：数据服务+技术授权

**Step 3 - 可复制性评估**：
- ✅ 垂直领域数据服务 → 可迁移至医疗、金融、工业
- ✅ "模型+数据"双轮驱动 → 通用AI商业范式
- ❌ 自动驾驶数据积累 → 需要长期行业深耕

**Step 4 - 竞争格局**：
- 自动驾驶数据服务细分领域头部
- 向具身智能延伸的战略布局

**Step 5 - 风险提示**：
- 具身智能商业化周期不确定
- 数据合规风险（时空数据涉及地理信息安全）

## 六、注意事项

1. **信息时效性**：定期更新，确保信息最新
2. **信息准确性**：交叉验证，避免单一来源
3. **分析深度**：避免浅层罗列，要有洞察
4. **可操作性**：结论要可指导决策
