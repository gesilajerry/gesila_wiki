# Cron晨报自动化发布工作流

## 背景

每日自动运行的 Cron 任务，通过 MiniMax 搜索 + 语义整理 + blog-publisher skill 发布到内网博客系统（Koala）。

## 工作流结构

### 当日运行的3条晨报管线

| 时间 | 类型 | 板块 | 数据源 |
|------|------|------|--------|
| 08:30 | 财经新闻 | 综合管理(forum_id=2) | mmx搜索财经要闻 |
| 10:15 | MLCC产业链 | 市场销售(forum_id=1) | mmx搜索+行业网站 |
| 11:15 | 半导体热点 | 市场销售(forum_id=1) | mmx搜索+行业网站 |

### 执行流程

1. 加载 blog-publisher skill（含自检清单）
2. 使用 mmx search 语义搜索（3-4条 `--q` 查询）
3. 整理为结构化简报（含今日要闻/技术进展/市场动态等章节）
4. 生成 Python 发布脚本 → 写入 /tmp/ 目录
5. 通过 blog-publisher API（Bearer Token + CSRF）发布
6. 发布到对应板块的"专业知识"分组（group_ids=[12]）

## 知识点

- 内网博客（Koala）板块：市场销售=1，综合管理=2，研发工程=4
- mmx search 不支持 `-t 24h` 或 `--limit`，只能用 `--q` 语义搜索
- `verify_token()` 预检：拿不到 uid 直接退出，避免无效发布
- CJK字数计算：编辑框限制10000字，需要提前拆分长文
- 公众号发布：需拆分多个自然段（每段不超过2000字符）
