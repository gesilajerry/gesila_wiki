# 中科院"原眼一号"：智能透射电镜的范式转变

**背景**
2026年5月，中国科学院大连化学物理研究所联合沈阳自动化研究所，成功研制具备全流程自主运行能力的智能透射电子显微镜"原眼一号"。实现"传样—成像—解析"全流程无人化，单日可分析200个样品、采集5000张图像、定量解析50万个颗粒。

**核心洞察**
"原眼一号"代表了从"精密仪器"到"具身智能系统"的范式转变：

| 传统模式 | 原眼一号模式 |
|----------|--------------|
| 人工传样、制样、找样 | 全流程自动化 |
| 单日10-20个样品 | 单日200个样品 |
| 人工图像分析，效率低 | 定量解析50万颗粒/日 |
| 测量与分析分离 | "测量即分析"一体化 |

**性能指标突破**：
- 通量：200样品/日 vs 传统20样品/日（10倍提升）
- 图像采集：5000张/日
- 颗粒解析：50万颗粒/日定量统计
- 全流程无人化：传样—成像—解析闭环

**对Jerry的意义**
- 原子级制造产业链跟踪又多了一个核心节点：先进表征装备智能化
- "原眼一号"的能力意味着：催化剂结构统计从数周压缩到数小时，研发效率大幅提升
- 这是"十五五"规划中被列为国家重大科技专项方向的标志性成果之一

**延伸思考**
"测量即分析"的范式转变将深刻影响：
1. 先进材料研发节奏：表征时间大幅缩短，实验迭代加速
2. 先进制程检测效率：晶圆级检测从抽检走向全检
3. 国产替代装备生态："原眼一号"类设备自主可控是原子级制造产业安全的重要保障
