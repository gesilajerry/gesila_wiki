# mmx新闻搜索：语义优先于时间过滤

**背景**
2026年5月，Hermes cron任务的新闻简报系统在生成半导体、AI、MLCC等垂直行业简报时，发现mmx search的`-t 24h`时间过滤参数对中文行业新闻无效，会返回大量无关结果（歌词、洗衣店等）。

**核心洞察**

## 问题现象

`mmx search query -t 24h --limit 8 "半导体 芯片 美国出口管制"` 返回的结果充满噪音，准确率极低。原因在于时间过滤是基于索引更新时间而非内容发布时间，且对中文语义的理解不足。

## 正确的搜索模式

**语义关键词精准搜索**，去掉时间参数：

```bash
# 每次最多10条，分3-4条查询覆盖不同维度
mmx search query --limit 10 "半导体芯片出口管制最新动态2026"
mmx search query --limit 10 "台积电中芯国际晶圆代工市场动态"
mmx search query --limit 10 "中国芯片国产替代突破进展2026"
```

**关键参数：**
- `--limit 10`：单次最多返回10条，避免稀释
- **语义化查询词**：包含时间敏感词（2026、最新）+ 行业词 + 具体细分领域
- **多维度组合**：不同角度的查询覆盖不同新闻源，避免重复

## 搜索维度覆盖示例（半导体）

| 维度 | 查询关键词 |
|------|-----------|
| 出口管制 | "半导体芯片出口管制最新动态2026" |
| 代工市场 | "台积电中芯国际晶圆代工市场动态" |
| 国产替代 | "中国芯片国产替代突破进展2026" |
| 技术突破 | "国产光刻机芯片制造突破2026" |

**对Jerry的意义**

这个发现让他在配置新闻简报cron任务时有了一套可复用的搜索策略，适用于任何垂直行业（半导体/MLCC/原子级制造/财经）。关键词公式：**「行业词 + 细分领域 + 时间敏感词 + 年份」**。

**延伸思考**

该方法论可迁移至其他中文搜索场景（如竞品监控、行业情报收集）。时间过滤对新闻类内容失效的根本原因是：中文内容更新频率不规律，很多有价值的行业内容发布超过24小时仍持续有效。语义搜索能捕获"今天仍被讨论的历史新闻"，这对行业分析更有价值。
