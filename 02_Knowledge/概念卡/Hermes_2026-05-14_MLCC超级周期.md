# MLCC超级周期

**背景**
2026年5月中旬，MLCC（多层陶瓷电容器）产业链密集发布重磅消息：三星电机计划对部分MLCC料号涨价（6月1日起）、村田未来两年投资800亿日元扩产MLCC、太阳诱电调价、中金公司预测AI服务器MLCC用量2027年翻番。多个迹象指向同一个结论：MLCC产业进入超级上行周期。

**核心洞察**
MLCC超级周期的驱动逻辑是"AI服务器单机用量暴增 + 产能扩张滞后"的结构性供需错配：

AI服务器的MLCC用量是传统服务器的5-8倍。HBM内存、高性能GPU、大功率电源管理等模块，都需要大量MLCC做滤波和去耦。AI服务器单机MLCC用量从传统服务器的约800颗，提升到约4000-6000颗（不同规格），且对高频、低ESR、高可靠性规格需求激增。

村田（全球MLCC龙头）扩产计划需要2-3年才能释放产能，而AI服务器需求增长在2026年已经开始爆量。三星电机率先涨价，是在需求最旺的规格上争夺产能分配权的策略动作。

中金公司数据显示，2027年AI服务器MLCC需求预计比2025年翻番。这意味着本轮超级周期不是季节性反弹，而是由AI算力基础设施扩张驱动的中长期趋势。惠伦晶体跟涨（晶体晶振领域）则显示涨价潮正从MLCC向其他被动元件蔓延。

**对Jerry的意义**
Jerry公司的真空设备、等离子体设备处于MLCC制造的上游（MLCC的陶瓷介质膜制备需要精密真空工艺），MLCC超级周期意味着：
- 上游原料和设备需求：MLCC扩产需要采购真空镀膜设备、精密刻蚀设备 → 公司等离子体设备需求可能受益
- 客户资本开支周期：村田、三星电机、太阳诱电扩产 → 设备采购需求增加
- 关注点：AI服务器用超小型MLCC（0201/01005规格）的技术壁垒更高，对设备精度要求更苛刻 → 可能是公司高端设备的机会窗口

**延伸思考**
超级周期的风险点在于：若村田大规模扩产的新产能集中在通用规格（常规MLCC），而AI服务器所需的高频、高精度MLCC仍由少数日厂商主导，则涨价可能持续更长时间。另外，需要关注HBM存储芯片的良率和量产节奏——若HBM量产遇阻，AI服务器出货量低于预期，MLCC超级周期的力度也会受影响。
