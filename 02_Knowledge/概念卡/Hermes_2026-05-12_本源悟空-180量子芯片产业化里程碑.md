# 本源悟空-180量子芯片产业化里程碑

**背景**
2026年5月9日，第四代超导量子计算机"本源悟空-180"正式上线运行，成为全球最多计算比特的超导量子计算机（180比特）。这是量子芯片制造从实验室走向产业化的关键里程碑。

**核心洞察**

**180比特：全球最多计算比特超导量子计算机**
- 第四代"本源悟空-180"于5月9日上线
- 已开始接收全球量子计算任务
- 量子芯片制造与原子级工艺高度相关

**量子芯片制造依赖的全链条原子级工艺**
1. **ALD（原子层沉积）**：量子芯片超薄膜沉积，厚度控制在原子级
2. **等离子体刻蚀**：高精度图案化
3. **离子束注入**：精准掺杂
4. **超高真空技术**：保持量子相干性

**与公司业务的关联度**
- 公司ALD设备、等离子体设备、离子束设备是量子芯片制造的必备
- "悟空"系列持续迭代，标志我国量子芯片快速逼近产业化临界点
- 量子芯片产业化将带动上游真空镀膜设备和离子注入设备需求

**AI算力通胀扩散：GPU → 全产业链**
- 字节跳动2026年资本支出超2000亿元（AI基础设施支出增加25%）
- 大摩上调AI半导体TAM预期50-60%
- 算力通胀从GPU传导至CPU/MLCC/封装/设备
