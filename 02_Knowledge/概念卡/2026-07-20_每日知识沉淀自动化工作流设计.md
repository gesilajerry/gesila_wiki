# 每日知识沉淀自动化工作流设计

## 问题
日常工作中产生的会话记录分散在多个 session 中，知识点容易丢失，工作日志需要手动编写。

## 方案
设计了一个 cron 定时任务，每天 20:00 自动执行知识沉淀工作流：

### 流程设计
1. **回顾当天工作**：通过 session_search 搜索当天会话记录，提取工作任务、关键决策、新知识点、会议纪要和融资/项目进展
2. **写入工作日志**：在 Obsidian Vault 的 `11-工作日志/` 下创建或追加当天的日志文件
3. **沉淀知识卡片**：将知识点提炼成概念卡片，按类型写入 gesila_wiki 对应目录
   - 知识点 → `02_Knowledge/概念卡/`
   - 方法论 → `02_Knowledge/方法论/`
   - 项目案例 → `02_Knowledge/案例库/`
4. **同步到 GitHub**：自动执行 git add/commit/push

### 路径配置
- Obsidian Vault: `~/Documents/Obsidian Vault/`
- gesila_wiki: `/Volumes/256G/gesila_wiki/`

### 格式规范
- 概念卡片：Markdown 含 YAML frontmatter (title, date, tags)
- 工作日志：Obsidian 格式
- 中文书写，简洁清晰

## 效果
实现了知识的"日结"机制，避免工作成果分散在对话历史中。
