# 本地LLM部署实战原始材料（2026-07-31）

> 来源：桌面会话「Gemma 3 4B 本地部署实战」（2026-07-31 11:20-14:34）原始步骤与实测输出存档。

## 一、用户提供的部署方案（入戏方案原文要点）

### 模型选择（8GB Mac）
| 模型 | 总参数 | Q4量化大小 | 内存占用 | 特点 |
|---|---|---|---|---|
| Gemma 3 4B | 4B | ~2.5GB | ~3GB | 多模态(文本+图像),稳定 |
| Gemma 3n E4B | 8B(有效4B) | ~3GB | ~3.5GB | 多模态(文本+图像+音频),更新更强 |

### 安装与下载
```bash
brew install llama.cpp
llama-cli --version
mkdir -p ~/models
# hf-mirror 下载（实测可用但慢）
curl -L -o ~/models/gemma-3-4b-it-q4km.gguf \
  "https://hf-mirror.com/unsloth/gemma-3-4b-it-GGUF/resolve/main/gemma-3-4b-it-Q4_K_M.gguf"
```

### 8GB Mac 优化参数（原始版）
```bash
llama-server -m ~/models/gemma-3-4b-it-q4km.gguf --port 8080 \
  -ngl 99 -c 2048 -t 4 --mlock --no-mmap -cb
```
参数含义：-ngl 99 全层 GPU / -c 2048 上下文上限 / -t 4 线程 / --mlock 锁内存防 swap / --no-mmap 减少内存碎片 / -cb 连续批处理

- Homebrew 6.0.12

- 磁盘：根分区 228Gi 总量，下载前剩余 36GB

### 2. ModelScope 下载（Gemma 3n E4B）
```
curl -L -C - -o ~/models/gemma-3n-e4b-it-q4km.gguf \

```
结果：4,539,054,208 字节（4.54GB），EXIT:0，稳定高速

### 3. Qwen3 8B 启动与 OOM
- `-ngl 99` / `-ngl 40`：`ggml_metal_synchronize: error: command buffer 0 failed with status 5` / `error: Insufficient Memory (00000008:***)` / `llama_decode() failed: -3`
- `-ngl 18`（Qwen3 8B 共 36 层，一半 CPU）：36 秒加载成功，无 OOM
- 实测速度：prompt 14.08 t/s，**eval 3.03 t/s**（330ms/token，不可用）
- 注意：`--mlock` / `--no-mmap` 在 v10180 显示 DEPRECATED，应改用 `--load-mode mlock/mmap`

### 4. Qwen3 8B 工具调用测试（成功）
请求：查询北京的天气，tools=[get_weather(city)], tool_choice=auto
返回：`"finish_reason":"tool_calls"`，tool_calls 参数 `{"city": "北京"}`，含 reasoning_content 中文思考过程，id: XC2Xy1mNE9Sa2cKwnMKu3yGbXdp7tdJX

### 5. Gemma 3 4B 表现
- 工具调用：忽略 tools，编造"墨迹天气"假数据（幻觉）
- 大 context：11508 tokens prompt 处理 91.5s（125.7 t/s），eval 8.88 t/s

### 6. Trae 实际请求体量
日志显示 Trae 发出 12435 / 12717 tokens 的大请求，4 slots 并发。

## 四、最终清理命令

```bash
# 1. 杀服务  2. 删模型
rm -rf ~/models          # 释放 14.5GB（4 个 GGUF）
brew uninstall llama.cpp ggml
rm -f ~/start-qwen3-agent.sh
# 验证：brew list 无 llama/ggml formula，家目录无残留
```

## 五、结论（会话最终交付）

- Gemma 3 4B：工具调用不可用 → 不适合 agent
- Qwen3 8B：工具调用完美但 8GB 机器 3 t/s → 不可用
- **Qwen3-4B：8GB Mac agent 正解**（工具调用强化 + 25+ t/s）
- 经验已沉淀至 llama-cpp 技能；Trae 需删除自定义模型配置
