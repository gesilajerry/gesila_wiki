### Git Push 失败（持续性问题）
- **现象**：`git push` 超时，osxkeychain/gh credential 读不到 token
- **原因**：网络到 GitHub 443 端口有代理拦截
- **解法**：使用 `~/.netrc` + `GIT_TERMINAL_PROMPT=0 git -c credential.helper=store push`
